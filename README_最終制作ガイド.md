# 第13回〜第15回 最終制作用サンプル

このフォルダーに、8種類のゲームと補助ファイルがあります。
ゲームを実際にプレイして、改良したい題材を1つ選び、ソースコードの一部分を読んで変更します。
ゼロから作る必要はありません。オリジナル制作も選択可能です。

| 題材 | 起動ファイル | 改良例 |
|---|---|---|
| 倉庫番 | sokoban.py | ステージ追加・移動ルール変更 |
| スキー | ski_game.py | 障害物・速度変更 |
| マインスイーパー | minesweeper.py | 盤面・周囲探索 |
| ローグライク | roguelike.py | 敵・アイテム追加 |
| テトリス | tetris.py | ブロック・得点ルール |
| 四目並べ | connect_four.py | CPU対戦・表示 |
| シューティング | shooting.py | 敵クラス継承・兵装 |
| 魚雷ゲーム | torpedo_game.py | 新艦種・兵装・レーダー・CPU（全体規模★10） |

倉庫番には `sokoban_demo.py`（完成・コメントなし）と
`sokoban_exercise.py`（演習用TODO）も同梱しています。
第13回の倉庫番演習には、先に配布される「倉庫番演習2ファイル」を使ってください。

## 起動

Python 3.13 例： `py -3.13 tetris.py` 。
テトリス・シューティングには同じ場所に `terminal_io.py` が必要です。
一部ゲームのキー操作には Windows のターミナルを使います。詳細は README.md を参照。

## GitHubへの登録

GitHubで空のリポジトリを作成し、`git clone <URL>` でローカルに取得します。
VS CodeでClone先フォルダーを開き、選んだゲームの必要なファイルをコピーしてください。
変更の区切りでCommitし、PushでGitHubにも反映します。

## 最終課題

まず自分で選んだプログラムを動かし、改良点を決めます。
改良後は実際に試し、動作や未完成箇所を説明できるようにします。
AIは補助として使用できますが、変更した内容を自分の言葉で説明できることが必要です。
正式な配点・提出期限・リポジトリの公開範囲は授業内で案内します。
